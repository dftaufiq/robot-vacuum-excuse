A small Python program that writes the one-line excuse a robot vacuum gives for missing a spot, to /output/entry.txt. The line is fixed and deterministic — the same 110-character line every run: the vacuum adopted the dust bunny under the couch, called Gerald, and refuses to eat its own child.

## Run it

```sh
python3 main.py
```
